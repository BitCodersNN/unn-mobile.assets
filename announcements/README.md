# Динамическая система промо- и информационных окон (`announcements`)

В этой директории хранятся JSON-конфигурации и изображения для динамических всплывающих окон в приложении **UNN Mobile**.

## Структура каталога

```text
announcements/
├── giveaways.json   # Розыгрыши и конкурсы (приоритет по умолчанию: 20, бейдж: «РОЗЫГРЫШ»)
├── ads.json         # Реклама и партнёрские акции (приоритет по умолчанию: 10, бейдж: «РЕКЛАМА»)
├── updates.json     # Уведомления о новых версиях и бета-сборках (приоритет по умолчанию: 30, бейдж: «ОБНОВЛЕНИЕ»)
├── images/          # Изображения карточек, предзагружаемые в локальный кэш устройства
└── README.md
```

### Как работает выбор и обновление объявлений
- При запуске приложения каталог читается мгновенно **из локального кэша**, а проверка обновлений (по SHA каталога в GitHub) и скачивание новых конфигов/картинок выполняются в фоне — изменения вступают в силу со следующего запуска.
- За один запуск показывается **не более одного** окна.
- Среди всех активных и подходящих по `period`, `target`, `policy` (и наличию закэшированных картинок) объявлений выбирается группа с максимальным `priority`, внутри которой случайно выбирается одно событие (с ротацией, чтобы не повторять одно и то же подряд при наличии нескольких кандидатов).

## Спецификация JSON-схемы

Все три файла (`giveaways.json`, `ads.json`, `updates.json`) используют единый формат корневого объекта:

```json
{
  "items": [ ... ]
}
```

### Поля элемента (`AnnouncementItem`)

| Поле | Тип | Обязательно | По умолчанию | Описание |
| :--- | :--- | :---: | :--- | :--- |
| `id` | `String` | Да | — | Уникальный идентификатор события. По нему на устройстве хранится статистика показов, переходов и закрытий. |
| `enabled` | `bool` | Нет | `true` | Позволяет быстро выключить событие без удаления записи из JSON. |
| `priority` | `int` | Нет | По категории (`30` / `20` / `10`) | Приоритет выбора, если одновременно активно несколько событий. |
| `badge` | `String?` | Нет | По категории (`РОЗЫГРЫШ` / `РЕКЛАМА` / `ОБНОВЛЕНИЕ`) | Текст плашки в шапке карточки. Передайте `null` или `""`, чтобы скрыть плашку. |
| `animation` | `String` | Нет | `"default"` | `"default"` — стандартное плавное появление окна; `"f1_tow"` — выезд болида Формулы-1 снизу вверх с тросом, пробуксовкой и вибрацией. |
| `title` | `String` | Да | — | Заголовок окна. |
| `text` | `String` | Да | — | Основной текст окна. |
| `images` | `List<String>` | Нет | `[]` | Относительные пути к картинкам внутри `announcements/` (например, `["images/giveaway_1.png"]`). Если список пустой — блок карусели скрыт. |
| `period` | `Object?` | Нет | `null` | Период активности события (`start_at`, `end_at`). |
| `policy` | `Object?` | Нет | См. ниже | Правила частоты показа и реакции на переход по ссылке или закрытие окна. |
| `action` | `Object?` | Нет | `null` | Основная кнопка действия (`label`, `url`). Если `null` — кнопка перехода не отображается (только закрытие). |
| `target` | `Object?` | Нет | `null` | Фильтр целевой аудитории по типу пользователя, каналу сборки, платформе, стору, версии и номеру сборки. |

### Объект `period` (период показа)

```json
"period": {
  "start_at": "2026-11-22T00:00:00+03:00",
  "end_at": "2026-12-05T23:59:59+03:00"
}
```

- Поддерживаются как полные даты со временем и часовым поясом (`2026-11-22T00:00:00+03:00`), так и короткие локальные даты (`2026-11-22`, где `end_at` трактуется включительно до конца дня `23:59:59.999`).
- Оба поля опциональны: `start_at: null` — без нижней границы, `end_at: null` — бессрочно.

---

### Объект `policy` (частота показа и реакция на действия)

```json
"policy": {
  "frequency": "once_per_day",
  "interval_hours": null,
  "max_shows": null,
  "stop_on_action": true,
  "frequency_after_action": null,
  "stop_on_dismiss": false
}
```

- **`frequency`** (`String`, по умолчанию `"once_per_day"`):
  - `"once"` — показать всего 1 раз за всё время.
  - `"every_launch"` — показывать при каждом запуске приложения (с учётом остальных ограничений).
  - `"once_per_day"` — не чаще 1 раза в календарный день (по локальному времени устройства).
  - `"interval_hours"` — не чаще чем раз в `interval_hours` часов (например, `"interval_hours": 72` — раз в 3 дня; по умолчанию 24 часа, если `interval_hours` не задан).
- **`interval_hours`** (`int?`, по умолчанию `null`):
  - Интервал в часах для режима `"frequency": "interval_hours"`.
- **`max_shows`** (`int?`, по умолчанию `null`):
  - Максимальное суммарное число показов данному пользователю (например, `5`). Если `null` — без лимита.
- **`stop_on_action`** (`bool`, по умолчанию `true`):
  - `true` — перестать показывать навсегда после нажатия на кнопку действия.
  - `false` — продолжать показывать даже после перехода по ссылке (по частоте `frequency_after_action` или основной `frequency`).
- **`frequency_after_action`** (`String?`, по умолчанию `null`):
  - Если `stop_on_action == false` и пользователь уже переходил по ссылке хотя бы раз, позволяет переключить частоту (например, до клика `"every_launch"`, после клика `"once_per_day"`).
- **`stop_on_dismiss`** (`bool`, по умолчанию `false`):
  - `true` — если пользователь закрыл окно крестиком, тапом вне окна или жестом «Назад», больше никогда его не показывать.
  - `false` — после простого закрытия продолжать показывать согласно `frequency` и `max_shows`.

### Объект `target` (таргетинг аудитории)

```json
"target": {
  "user_type": "all",
  "channel": "all",
  "platforms": ["android", "ios"],
  "stores": ["regular", "rustore", "googlePlay"],
  "min_version": null,
  "max_version": "0.7.0",
  "min_build": null,
  "max_build": 471
}
```

- **`user_type`** (`String`, по умолчанию `"all"`):
  - `"all"` — для всех пользователей.
  - `"student"` (также поддерживается `"students"`) — только для студентов.
  - `"employee"` (также поддерживается `"employees"`) — только для сотрудников.
- **`channel`** (`String`, по умолчанию `"all"`):
  - `"all"` — все сборки.
  - `"stable"` — только релизные сборки.
  - `"beta"` — только тестовые сборки.
- **`platforms`** (`List<String>?`, по умолчанию `null` — все платформы):
  - Поддерживаются значения `"android"`, `"ios"`.
- **`stores`** (`List<String>?`, по умолчанию `null` — все сторы):
  - Поддерживаются значения `"regular"`, `"rustore"`, `"googlePlay"`.
- **`min_version` / `max_version`** (`String?`, по умолчанию `null`):
  - Границы семантической версии приложения (включительно), например `"0.7.0"`.
- **`min_build` / `max_build`** (`int?`, по умолчанию `null`):
  - Границы номера сборки (включительно), например `471`.

---

### Объект `action` (кнопка действия)

```json
"action": {
  "label": "Перейти в Telegram-канал",
  "url": "https://t.me/unn_mobile"
}
```

- **`label`** (`String`) — текст на кнопке.
- **`url`** (`String`) — ссылка, открываемая при нажатии.
- Если `action` равен `null` или отсутствует, кнопка действия не отображается.
